# AleCoin — визуальный дизайн сайта — дизайн-спецификация

Дата: 2026-10-01
Статус: одобрено, готово к планированию реализации

## Контекст и цель

Продолжение `docs/superpowers/specs/2026-09-24-alecoin-site-design.md`. Сайт
(`site/`) функционально готов, задеплоен на GitHub Pages и проверен вживую, но
не оформлен: голый HTML на стандартных стилях заготовки Next.js.

Цель — дать сайту собственный узнаваемый внешний вид. Две равноценные
аудитории:

- **гость из портфолио** (обычно с компьютера, часто без MetaMask) — должен
  сразу понять, что это за проект и как он работает;
- **получатель награды** (с телефона, во встроенном браузере MetaMask) —
  должен без лишнего текста получить токены.

Логика работы с контрактом (подключение кошелька, подписи EIP-712, вызовы
`transfer` / `claimReward`, разбор ссылок, перевод ошибок) **не меняется**.
Исключения — несколько небольших улучшений удобства, перечисленных в разделе
«Изменения поведения».

## Визуальное направление: «Тёмный паб»

Тёплая тёмная гамма в духе ирландского паба. Только тёмная тема, без
светлого варианта и без переключателя.

### Палитра

| Токен | Значение | Назначение |
|---|---|---|
| `pub` | `#12291f` | фон страницы (тёмно-зелёный) |
| `amber` | `#e0a83a` | акцент: логотип, основные кнопки, суммы, метки, ссылки |
| `cream` | `#f3e9d2` | основной текст; текст на кнопках — `pub` |
| карточка | `cream` с прозрачностью ~6% | фон карточек (панелей) |
| рамка | `cream` с прозрачностью ~12% | рамки карточек и разделители строк |
| приглушённый текст | `cream` с прозрачностью ~70% | пояснения, подписи |

### Шрифты

- **Playfair Display** (600, 800) — логотип, заголовки, крупные суммы.
- **Inter** (400, 600) — весь остальной текст.
- Адреса и хеши — системный моноширинный шрифт.
- Оба шрифта с кириллицей. Подключаются через npm-пакеты **Fontsource**
  (файлы шрифтов попадают в сборку и раздаются с GitHub Pages) — сборка и
  сайт не зависят от доступности Google Fonts.

### Типовые элементы

- Метка раздела: маленькие заглавные буквы с разрядкой, цвет `amber`
  («ВАШ БАЛАНС», «ИСТОРИЯ ОПЕРАЦИЙ»).
- Карточка: полупрозрачный фон, тонкая рамка, скруглённые углы.
- Основная кнопка: фон `amber`, текст `pub`, полужирный. Неактивная/занятая
  кнопка — приглушена, не нажимается.
- Второстепенная кнопка: контур `amber`, прозрачный фон.
- Поле ввода: тонкая рамка, прозрачный фон, кремовый текст; при фокусе
  рамка `amber`.
- Плашка-сообщение: янтарная рамка и слегка янтарный фон, текст по центру.
  Для ошибок — тот же спокойный стиль (не красный).

### Значок

Янтарная монета с тёмным трилистником (клевер — символ Ирландии) — SVG.
Используется в шапке рядом с названием «AleCoin» и как иконка вкладки
браузера (заменяет стандартный `favicon.ico`).

## Технология стилей

- **Tailwind CSS v4** (через PostCSS-плагин, как рекомендует документация
  Next.js). Палитра и шрифты описываются один раз как токены темы в
  `globals.css`; разметка использует их по именам (`bg-pub`, `text-amber`,
  `font-display` и т. п.).
- Стандартные стили заготовки Next.js из `globals.css` удаляются.
- Общие повторяющиеся элементы выносятся в небольшие компоненты (шапка,
  карточка, кнопка, плашка-сообщение), чтобы файлы страниц оставались
  короткими. Точный набор и имена — в плане реализации.

## Страницы

### Шапка (все страницы)

Слева значок + «AleCoin» (ссылка на главную). Справа — если кошелёк
подключён на этой странице — сокращённый адрес в овальной рамке
(`0x58EE…d70b`); на главной без кошелька — второстепенная кнопка
«Подключить кошелёк».

### `/` — кошелёк не подключён

Две колонки на компьютере, одна на телефоне:

- слева: метка «ТОКЕН ALE · POLYGON», заголовок (смысл — «награды, которые
  выдаются вручную»), 1–2 предложения о сути (владелец подписывает награду в
  кошельке, получатель забирает токены по одноразовой ссылке, всё проверяет
  смарт-контракт, без сервера и базы данных), основная кнопка «Подключить
  кошелёк»;
- справа: карточка «Как это работает» — три пронумерованных шага
  (владелец создаёт и подписывает награду → получатель получает одноразовую
  ссылку → открывает её, подключает кошелёк и забирает ALE);
- под ними — короткая строка: получили ссылку — просто откройте её; ссылки
  нет — напишите владельцу в Telegram.

Тексты — простой русский язык; предыстория названия токена не упоминается.

### `/` — кошелёк подключён

Две колонки на компьютере, одна на телефоне (порядок: баланс → перевод →
история):

- карточка «Ваш баланс»: сумма крупно (Playfair), «ALE» — цветом `amber`;
- карточка «Перевести токены»: поля «Адрес получателя (0x…)» и «Сумма ALE»,
  кнопка «Отправить»;
- карточка «История операций»: строки с круглым значком типа операции
  (награда — янтарная звёздочка, отправлено — ↑, получено — ↓), подписью,
  сокращённым адресом второй стороны и суммой справа (поступления — `amber`
  со знаком «+», списания — со знаком «−»). Каждая строка — ссылка на
  транзакцию в PolygonScan (новая вкладка). Пустая история — короткая фраза
  «Операций пока нет».

### `/claim`

Одна карточка по центру, рассчитана на телефон:

- до получения: метка «ВАМ НАГРАДА», сумма очень крупно цветом `amber`, под
  ней «ALE», строка «на адрес 0x3a…91», большая основная кнопка «Получить»;
- после получения: значок-галочка, «Токены получены!», «N ALE уже в вашем
  кошельке», ссылка «Посмотреть транзакцию →» (PolygonScan), ссылка «На
  главную»;
- ошибка: сумма приглушена, под ней плашка с текстом ошибки (тексты из
  существующего `translateError`), кнопка «Получить» остаётся доступной для
  повтора (отмена, сбой сети и т. п.), кроме двух окончательных ошибок
  контракта — «награда уже получена» и «ссылка повреждена или
  недействительна» — после них кнопка скрывается;
- повреждённая ссылка: оформленный экран в той же карточке с текстом
  «Ссылка повреждена» и ссылкой «На главную».

### `/admin`

Одна карточка в том же стиле: заголовок «Выдача наград», поля «Адрес друга»
и «Сумма ALE», основная кнопка «Создать награду». Готовая ссылка — в рамке
(поле только для чтения, по фокусу выделяется целиком) с кнопкой
«Скопировать»; после копирования кнопка на пару секунд меняется на
«Скопировано». Скрытость маршрута (`noindex`, `robots.txt`, нет в меню) не
меняется.

### 404

Оформленная страница «Страница не найдена» со ссылкой «На главную».

## Адаптивность

- Основная ширина проверки — телефон (~375 px, встроенный браузер
  MetaMask) и обычный ноутбук/монитор.
- Двухколоночные раскладки на узких экранах складываются в одну колонку.
- Кнопки и поля — удобной для пальца высоты (не меньше ~44 px).
- Длинные адреса и ссылки не ломают ширину страницы (сокращение или перенос).

## Изменения поведения

Небольшие изменения сверх оформления, одобренные вместе с дизайном:

1. **Состояние «занято».** Пока идёт действие с кошельком (подключение,
   подпись, транзакция), соответствующая кнопка заблокирована и показывает
   этап: «Подтвердите в MetaMask…» до подписи/отправки, «Ждём сеть…» пока
   транзакция подтверждается. Защищает от двойного нажатия.
2. **Ссылки на PolygonScan** у строк истории и после получения награды
   (адрес обозревателя берётся из существующей конфигурации сети
   `NETWORK.blockExplorerUrl`).
3. **Кнопка «Скопировать»** в админке (`navigator.clipboard.writeText`); если
   буфер обмена недоступен — ссылку по-прежнему можно выделить и
   скопировать вручную.
4. **Формат чисел:** суммы ALE с пробелами между разрядами и без лишнего
   «.0» (`1 250`, `0.5`).

## Тестирование

- **Vitest** — для новых вспомогательных функций: сокращение адреса, формат
  суммы ALE, сборка ссылки на транзакцию в PolygonScan.
- Существующие тесты (`claimLink`, `errors`, `signClaim`) должны проходить
  без изменений.
- **`npm run build`** — обязательная финальная проверка (полная проверка
  типов и статический экспорт).
- Ручная проверка в браузере на компьютере, включая узкую ширину окна.
- Ручной прогон на телефоне во встроенном браузере MetaMask: создание
  награды в `/admin` → копирование ссылки → получение на `/claim` → повторная
  попытка отклонена — как при проверке 2026-09-24.

## Вне рамок

- Светлая тема и переключатель темы.
- Анимации сложнее простых переходов при наведении/фокусе.
- Изменения логики контракта, подписи и разбора ссылок.
- Открытие ссылок в обычном мобильном браузере без MetaMask (WalletConnect)
  — отдельная будущая задача.
- Деплой в Polygon mainnet.
